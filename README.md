# SAIT Microsoft Fabric Exploratory Sandbox

Lab guide for the SAIT Microsoft Fabric exploratory sandbox on CloudLabs.

- `Labfiles/gettingstarted.md`: starter page shown to learners.
- `Labfiles/masterdoc.json`: master doc that lists the lab guide pages.
- `media/`: screenshots used by the guide.

Deployment templates live in the CloudEasyTemplates repo under `AZ-Templates/sait-fabric-exploratory-sandbox`.
